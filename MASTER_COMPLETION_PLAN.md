## Status and Evidence Rules

Statuses: `NOT_STARTED`, `IN_PROGRESS`, `BLOCKED`, `IMPLEMENTED`, `TESTING`, `VERIFIED`, `COMPLETE`. Completion requires code integration, focused tests, integration/E2E tests where applicable, failure remediation, rerun, and code-level verification. Mocks/fixtures may test boundaries but never count as proof of a real external submission. PostgreSQL/Prisma remains authoritative; Redis/BullMQ is coordination; private S3-compatible storage holds objects; MongoDB is excluded.
